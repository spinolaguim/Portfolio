# Portfolio

Site de portfólio de fotos do Guilherme (spinolagui): álbum, presets para Lightroom e contatos, em português, inglês e espanhol.

## Como editar

- **Retrato do topo:** salve a foto como `img/retrato.jpg` (vertical, de preferência 800×1000 px ou maior). Sem ela, aparece um “G” no lugar.
- **Posts do Instagram no rodapé:** edite a lista `IG` em `js/site.js`. Em cada item, `n` é a foto do álbum usada como miniatura e `post` pode receber o link real do post (ex.: `https://www.instagram.com/p/ABC123/`); com o link, a janela mostra o post oficial do Instagram.
- **Fotos por categoria:** lista `ALBUM` em `js/site.js`. Textos dos três idiomas: objeto `T`, no mesmo arquivo.
